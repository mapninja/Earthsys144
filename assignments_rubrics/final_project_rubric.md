# Assignments & Rubrics - Final Project StoryMap

## Final Project Overview

Completion of an individual final project using spatial data and spatial methods is a course requirement. Working with classmates to talk through ideas, troubleshoot tools, and improve one another's work is absolutely fine, and usually a very good idea, but each student must submit an individual final project and an individual final StoryMap.

The final presentation of the project should be done using ArcGIS Online StoryMaps. StoryMaps are an excellent way to create a coherent narrative with maps, text, images, multimedia, and all the little details that make a project feel complete and intentional.

This project is not about saving the world in one quarter. It is about doing something spatial, thoughtful, creative, and manageable with the tools and methods from the course. The best projects are often the ones that control scope, stay curious, and clearly reflect the student's own interests. Edible plants on campus? Recipe atlas? Geocoded Beirut lyrics on a globe with audio clips? Elephant roaming territories from trajectory data? A 3D print of favorite climbing routes with terrain-enhanced detail? All fair game. Spatial data is everywhere. Have fun with it.

## StoryMap Expectations

Your StoryMap should include the following, though artistic license does not require this exact order:

- A title and header image area, with your name and identifying information.
- A text abstract of your spatial question and area of interest.
- Supporting images, multimedia, and an overview map where appropriate.
- A clear explanation of your methods and workflows.
- Final results, with a map or mapped product as the centerpiece of most projects.
- Links to final dataset products of the project, stored on Github, or the Stanford Digital Repository, if appropriate.
- A bibliography and data sources section, ideally using bullets for readability.
- Credits for images, video, and any other borrowed materials.

## Project Emphasis

- Do not try to save the world. Control the scope and make something you can finish well.
- Have fun. The project should reflect your interests, creativity, and curiosity.
- Details count. Spelling, formatting, credits, layout, and extra touches will absolutely be noticed.
- If your project includes non-sensitive datasets you created, share them if you can.
- All final project submissions should use ArcGIS StoryMaps as the final presentation format.

## Grading Notes

- This rubric evaluates the final StoryMap as both an analytic product and a communication product.
- The map, interactive element, or other spatial output should usually be the centerpiece, but it should be supported by enough explanation that another person can follow what was done.
- Scope control still matters at the final stage. A smaller project completed thoughtfully is usually stronger than an overextended one that gestures at too many things.
- Proper sharing matters. Be sure the StoryMap and the maps and layers inside it are shared correctly with the Earthsys144 Final Project group so they can actually be viewed.
