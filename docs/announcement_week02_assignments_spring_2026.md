# Week 02 Assignment Announcement: Creating and Collecting Spatial Data

Dear Students,

This week, we are shifting from working with existing spatial data toward creating and collecting spatial data ourselves. That is an important transition in GIS and remote sensing. A great deal of geospatial work is not only about analyzing data that already exists, but also about deciding what should become data, how it should be represented, and how it should be collected in a consistent and usable way.

This week's assignment includes three graded components, but one of them is a choice. You should complete:

1. **One** of the two `PICK_ONE_TO_TURN_IN` labs:
   - Field Data Collection with ArcGIS Online and Field Maps
   - Georeferencing with QGIS and AllMaps.org
2. **Editing with QGIS**
3. **Collections, Images, Bands, and Pixels in Google Earth Engine**

Together, these introduce several different ways of thinking about data creation: mobile field data collection, georeferencing historical maps, digitizing vector features in QGIS, and working with raster structure in Google Earth Engine through collections, images, bands, and pixels.

Please choose the `PICK_ONE_TO_TURN_IN` lab that best matches your interests. If you hear older references in prerecorded materials suggesting a different requirement structure, please follow the current written Week 02 materials instead.

## [Georeferencing with QGIS and AllMaps.org](https://mapninja.github.io/Earthsys144/week02/02_PICK_ONE_TO_TURN_IN_georeferencing_with_qgis_and_allmaps_org.html)

In this exercise, you will georeference a historical map so it can be aligned with a PLSS reference grid and a modern basemap. This workflow is especially useful if you are interested in historical GIS, archival materials, and the question of how older maps can be turned into usable spatial data.

## [Data Creation in QGIS: Editing with Points, Lines, and Polygons](https://mapninja.github.io/Earthsys144/week02/03_TURN_IN_data_creation_in_qgis.html)

In this exercise, you will create spatial data by digitizing features from aerial imagery in QGIS. You will work with points, lines, and polygons to represent trees, paths, rows, and structures at the Stanford Teaching Farm. This is a hands-on introduction to vector data creation and interpretation. As you work, you will make decisions about how different real-world features should be represented in a GIS dataset, which is one of the most important parts of learning how spatial data is constructed.

## [Field Data Collection with ArcGIS Online and Field Maps](https://mapninja.github.io/Earthsys144/week02/01_PICK_ONE_TO_TURN_IN_introducing_arcgis_fieldmaps_and_arcgis_online_for_data_collection.html)

In this exercise, you will build a field data collection application that can be distributed to multiple field users, with observations collected into a shared central database. You will create feature layers, design a field form, and use controlled value lists, or domains, to improve consistency and data quality. This workflow introduces the practical realities of field-based GIS and should leave you feeling much more confident about how to build your own mobile data collection projects using the ArcGIS Online platform.

## [Collections, Images, Bands, and Pixels in Google Earth Engine](https://mapninja.github.io/Earthsys144/week02/04_TURN_IN_introducing_collections_and_pixels_in_earth_engine.html)

In this exercise, you will begin working with raster and remote sensing concepts in Google Earth Engine. The main goal is to understand how Earth observation datasets are structured: as collections of images, made up of bands, with each band storing pixel values. You will practice filtering image collections, selecting bands, inspecting pixel values, and using raster logic to isolate conditions of interest. This is a foundational step toward reading satellite imagery as data, rather than only as a picture.
