# Week 05 Rubric: Raster Analysis, Terrain Modeling, Watersheds, and Earth Engine

The canonical Week 05 rubric is maintained here:

- [Assignments & Rubrics - Week 05](../assignments_rubrics/week05_Rubric.md)

Use that rubric for Canvas setup and grading. It treats Week 05 as one 10-point assignment with four graded components:

1. Terrain Data Preparation and DEM Merging with QGIS
2. Visibility Analysis with QGIS
3. Watershed with QGIS & WhiteBox Tools
4. Basic Raster Analysis with Google Earth Engine

The optional StoryMaps workshop is support material and is not part of the Week 05 score unless separately assigned.
