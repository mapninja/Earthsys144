# Announcement: Whitebox Tools Update for QGIS

Dear Students,

If you are trying to update or reinstall **WhiteboxTools** in QGIS, please stop and use the new workflow instead. The older WhiteboxTools QGIS plugin has been deprecated, and the current plugin you should install is **Whitebox Workflows for QGIS**.

We have updated the Week 00 installation guide to match the new setup. When you install the plugin, QGIS may prompt you to **Install using pip**. If that prompt appears, please allow it so the Python dependency can be installed correctly.

## What You Should Do

1. Open the updated installation instructions in Week 00:
   - [Installing QGIS and Plugins](../week00/07_installing_qgis_and_plugins.md)
2. In QGIS, go to **Plugins > Manage and Install Plugins**
3. Search for **Whitebox Workflows**
4. Install **Whitebox Workflows for QGIS**
5. If QGIS prompts you to **Install using pip**, allow it
6. Restart QGIS if needed and check **Processing > Toolbox** for the Whitebox Workflows provider

## Key Links

- [Updated Week 00 QGIS installation guide](../week00/07_installing_qgis_and_plugins.md)
- [Whitebox Geo QGIS Quick Start](https://www.whiteboxgeo.com/manuals/qgis/quick-start.html)

## Quick Notes

- Do not follow older instructions for the deprecated WhiteboxTools plugin
- If the plugin does not appear right away, restart QGIS and check the Processing Toolbox again
- If you run into trouble, use the updated Week 00 guide before trying older setup steps
