# Announcement: Whitebox Tools Update for QGIS

Dear Students,

If you are trying to update or reinstall **Whitebox Tools** in QGIS, please use the Week 00 Whitebox installation guide instead of the newer Whitebox Workflows path. The course labs will use the original **WhiteboxTools for QGIS** plugin together with the standalone Whitebox Tools binary package.

## What You Should Do

1. Open the Week 00 Whitebox guide:
   - [Installing Whitebox Tools](../week00/11_installing_whitebox_tools.md)
2. Check your Mac chip type with **About This Mac** if you are on a Mac
3. Download the correct Whitebox Tools binary package for your operating system
4. Install **WhiteboxTools for QGIS** from the QGIS Plugin Manager
5. Point QGIS at the `whitebox_tools` executable
6. Restart QGIS if needed and check **Processing > Toolbox** for the **WhiteboxTools** provider

## Key Links

- [Week 00 Whitebox installation guide](../week00/11_installing_whitebox_tools.md)
- [Week 00 QGIS installation guide](../week00/07_installing_qgis_and_plugins.md)

## Quick Notes

- Do not follow the Whitebox Workflows instructions for this course
- If the plugin does not appear right away, restart QGIS and check the Processing Toolbox again
- If you run into trouble, use the Week 00 Whitebox guide before trying older setup steps
