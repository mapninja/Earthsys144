## Exercise Notes

## [01 - TURN IN - Terrain Data Preparation and DEM Merging with QGIS](https://mapninja.github.io/Earthsys144/week05/01_TURN_IN_terrain_and_visibility_with_qgis.html)

This exercise introduces raster preparation through two DEMs with different resolution and coverage. You will inspect valid-data and `NoData` areas, create hillshades, resample one raster to match another, and use conditional logic to merge the two DEMs into a single terrain surface.

## [02 - TURN IN - Visibility Analysis with QGIS](https://mapninja.github.io/Earthsys144/week05/02_TURN_IN_visibility_analysis_with_qgis.html)

This exercise uses a DEM as an analytical surface for visibility. You will create a terrain profile along a line of sight, run a viewshed from an observation point, and export a layout that communicates the viewing station, profile, line of sight, and visible terrain.

## [03 - TURN IN - Watershed with QGIS & WhiteBox Tools](https://mapninja.github.io/Earthsys144/week05/03_TURN_IN_watershed_with_qgis_and_whitebox_tools.html)

This exercise extends terrain analysis into hydrologic modeling. You will derive flow direction and flow accumulation from a DEM, extract a modeled stream raster, create and snap a pour point, delineate the watershed draining to that outlet, and convert the modeled stream network to vector lines.

## [04 - TURN IN - Basic Raster Analysis with Google Earth Engine](https://mapninja.github.io/Earthsys144/week05/04_TURN_IN_basic_raster_analysis_with_google_earth_engine.html)

This exercise introduces raster analysis in Google Earth Engine. You will work with image bands, masks, terrain derivatives, zonal summaries, distance rasters, and edge effects. The final submission asks you to modify the focal state in the buffered power plant distance analysis and submit a saved Earth Engine **Get Link** URL inside a PDF.

## [05 - OPTIONAL - Introducing StoryMaps on ArcGIS Online](https://mapninja.github.io/Earthsys144/week05/05_OPTIONAL_introducing_storymaps_on_arcgis_online.html)

This optional workshop introduces ArcGIS StoryMaps as the final project presentation format. It is meant to help you become familiar with the StoryMaps builder, content blocks, map blocks, previewing, publishing, and sharing settings before the final project ramps up.
