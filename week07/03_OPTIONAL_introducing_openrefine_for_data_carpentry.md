## Overview

OpenRefine is an open-source tool for cleaning, restructuring, reconciling, and enriching tabular data. In this course, it supports workflows where spatial data begin as messy spreadsheets, address lists, or web API responses rather than ready-to-map GIS layers.

## What You Should Understand After This Lab

By the end of a completed version of this exercise, you should be able to explain:

- why data cleaning matters before geocoding or mapping
- how OpenRefine stores a repeatable history of cleaning operations
- how facets help identify inconsistent values
- how expressions can transform values across many rows

> **Concept note:** Data carpentry means preparing data so that analysis tools can use it reliably. In GIS work, this often means standardizing place names, cleaning address fields, checking coordinate columns, and removing values that would cause mapping or analysis errors.
